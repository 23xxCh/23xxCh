# 理论分析框架

## 1. Surge-Cast 算法收敛性分析

### 1.1 问题定义

**目标**: 证明 Surge-Cast 算法在理想气体场中能够收敛到气体源。

**假设**:
1. 气体浓度场满足单调递减性质：距离源越远，浓度越低
2. 风场在短时间内保持稳定
3. 传感器测量无噪声

### 1.2 收敛性定理

**定理 1**: 在理想气体场中，Surge-Cast 算法的 SURGE 阶段使机器人到源的距离单调递减。

**证明思路**:
1. 设源位置为 $s = (s_x, s_y)$，机器人位置为 $p_t = (x_t, y_t)$
2. 风向为 $w = (w_x, w_y)$，逆风方向为 $-w$
3. SURGE 阶段移动方向：$d = -w / \|w\|$
4. 新位置：$p_{t+1} = p_t + \alpha \cdot d$
5. 距离变化：$\|p_{t+1} - s\| \leq \|p_t - s\|$ （当风向指向源时）

### 1.3 收敛条件

- SURGE 阶段：当机器人处于羽流内时，逆风移动减少到源的距离
- CAST 阶段：当羽流丢失时，横向搜索重新捕获羽流

**收敛时间复杂度**: $O(d_0 / \alpha)$，其中 $d_0$ 是初始距离，$\alpha$ 是步长

## 2. 粒子滤波一致性分析

### 2.1 粒子滤波框架

状态空间模型：
- 状态：$x_t = (x, y)$ 气体源位置
- 观测：$z_t$ 气体浓度测量

### 2.2 一致性定理

**定理 2**: 在高斯羽流模型下，粒子滤波估计收敛到真实源位置。

**证明思路**:
1. 观测模型：$p(z_t | x_t) \propto \exp(-\frac{(z_t - C(x_t))^2}{2\sigma^2})$
2. 后验分布：$p(x_t | z_{1:t}) \rightarrow \delta(x_t - x^*)$ 当 $t \rightarrow \infty$
3. 粒子权重收敛：$w_i \rightarrow 1$ 对于真实源附近的粒子

### 2.3 收敛速率

- 粒子数 $N$：估计误差 $O(1/\sqrt{N})$
- 观测次数 $T$：方差 $O(1/T)$

## 3. 融合算法理论框架

### 3.1 融合策略

加权融合：
$$x_{fused} = w_{surge} \cdot x_{surge} + w_{pf} \cdot x_{pf}$$

权重计算：
$$w_{pf} = \alpha \cdot confidence_{pf}$$
$$w_{surge} = 1 - w_{pf}$$

### 3.2 融合最优性

**定理 3**: 在独立估计假设下，加权融合的估计误差小于单一算法。

**证明**:
设 Surge-Cast 误差方差为 $\sigma_s^2$，粒子滤波误差方差为 $\sigma_p^2$，则融合误差方差：
$$\sigma_{fused}^2 = w_s^2 \sigma_s^2 + w_p^2 \sigma_p^2$$

最优权重：$w_p^* = \frac{\sigma_s^2}{\sigma_s^2 + \sigma_p^2}$

## Surge-Cast 收敛性证明

### 假设条件

1. 气体浓度场满足高斯烟羽模型
2. 风场在短期内稳定
3. 机器人速度有界 $v \in [v_{min}, v_{max}]$

### 定理 1：Surge 阶段收敛性

在 Surge 阶段，若机器人沿浓度梯度方向移动，则期望距离源的位置单调递减。

**证明：**

设源位置为 $S = (x_s, y_s)$，机器人位置为 $R_t = (x_t, y_t)$。

距离函数：$D_t = \|R_t - S\|$

在 Surge 阶段，机器人沿梯度方向移动：
$$R_{t+1} = R_t + \alpha \nabla C(R_t)$$

其中 $\alpha$ 为步长，$\nabla C$ 为浓度梯度。

根据高斯烟羽模型，浓度梯度指向源方向：
$$\nabla C(R_t) \propto (S - R_t)$$

因此：
$$D_{t+1} = \|R_{t+1} - S\| = \|R_t + \alpha \nabla C - S\| < \|R_t - S\| = D_t$$

**证毕。**

### 定理 2：Cast 阶段探索性

当浓度下降时，Cast 阶段通过横向搜索重新定位烟羽。

设横向移动距离为 $L$，搜索角度为 $\theta$。

成功重新定位烟羽的概率：
$$P_{detect} = 1 - e^{-\lambda L \sin\theta}$$

其中 $\lambda$ 为烟羽宽度参数。

### 算法复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Surge 更新 | $O(1)$ | $O(1)$ |
| Cast 更新 | $O(1)$ | $O(1)$ |
| 风向估计 | $O(n)$ | $O(n)$ |
| 粒子滤波更新 | $O(N_p)$ | $O(N_p)$ |

其中 $n$ 为采样数，$N_p$ 为粒子数。
