# Issue tracker: Gitee

Issues and PRDs for this repo live as Gitee issues. Use the `git` CLI or Gitee web API for all operations.

## Conventions

- **Create an issue**: Use Gitee web interface or API
- **Read an issue**: Visit `https://gitee.com/cxx450/h2track/issues/<number>`
- **List issues**: Visit `https://gitee.com/cxx450/h2track/issues`
- **Comment on an issue**: Use Gitee web interface
- **Apply / remove labels**: Use Gitee web interface
- **Close**: Use Gitee web interface

## When a skill says "publish to the issue tracker"

Create a Gitee issue via the web interface.

## When a skill says "fetch the relevant ticket"

Visit the issue URL directly or use the Gitee API.
