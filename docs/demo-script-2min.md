# 2-Minute Demo Script

## 开场

各位老师好，现在演示的是我们做的氢气泄漏追踪机器人仿真系统。这个机器人是二轮差速底盘，搭载了激光雷达和氢气检测能力。今天我主要展示一条完整闭环，也就是机器人能够先自主巡检，检测到氢气后自动切换到追踪模式，在追踪过程中继续避障和规划运动，最后在泄漏源附近报警并停车。

## 演示过程

正式开始前，我会先运行 `demo_prep`，清理残留进程并检查当前环境是否适合演示。然后我启动 `demo.launch.py`，把 Gazebo、Nav2、GADEN 和任务管理节点一起拉起。系统起来以后，我再运行 `demo_selfcheck`，只有自检通过，才进入正式演示。

现在可以看到，机器人先按照预设巡检路线自主移动。这一阶段重点看它的巡检状态和导航是否连续。当机器人进入泄漏气体影响区域以后，氢气浓度会上升，系统会从巡检模式切换到确认和追踪模式。接下来机器人不会直接盲目往前冲，而是结合当前浓度变化和导航规划，边追踪边避障，继续向泄漏源附近逼近。最后当系统判断已经到达源点附近时，机器人会停止运动，同时给出报警结果，表示这次泄漏源搜索完成。

## 结束总结

通过这次演示，可以说明当前系统已经具备了自主巡检、氢气检测、泄漏源追踪、避障和报警的完整闭环能力。现阶段系统仍然以仿真验证为主，对启动时序、环境稳定性和追踪策略还可以继续优化。下一步我们会重点提升演示稳定性、实验重复性，以及更真实气体场下的追踪效果。
