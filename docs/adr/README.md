# Architecture Decision Records

This directory contains architecture decision records (ADRs) for the H2Track project.

## Format

Each ADR is a markdown file named `NNNN-title.md` where `NNNN` is a sequential number.

## Template

```markdown
# ADR-NNNN: Title

## Status

Proposed / Accepted / Deprecated / Superseded by ADR-NNNN

## Context

What problem are we solving?

## Decision

What did we decide?

## Consequences

What are the trade-offs?
```
